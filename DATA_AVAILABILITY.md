# Data and Code Availability

This repository provides the public reproducibility materials for the study:

**Semantic Stability in the King James Bible: Comparing the 1611 and 1769 Editions**  
*A Human-in-the-Loop Embedding Study of Textual Drift Using the InterLink Research Platform*

Repository: <https://github.com/Saorsa-Ind/kjv-1611-1769-semantic-stability-study>  
Release tag: `v1.0.1`  
Zenodo DOI: forthcoming

## Available Materials

The repository includes the generated study outputs, figures, architecture documentation, manifest files, and validation materials used to inspect and verify the reported study results.

Included materials are organized as follows:

| Path | Description |
|---|---|
| `data/coverage/` | Corpus coverage, alignment, exception, and scope-registry outputs. |
| `data/drift/` | Aligned drift-pair outputs and drift-index summaries. |
| `data/thresholds/` | Threshold summaries, unit-level drift labels, and ranked outlier outputs. |
| `data/permutation/` | Null-model, permutation, stability-gap, and statistical diagnostic outputs. |
| `data/hitl/` | Human-in-the-loop annotation, category count, and enrichment outputs. |
| `data/exclusive/` | KJV 1611 exclusive corpus inventory outputs. |
| `figures/` | Final figures used in the manuscript. |
| `architecture/` | Polished study architecture and design-definition documents. |
| `notebooks/` | Validation, exploratory analysis, figure-generation, table-support, and study-note notebook materials. |
| `manifest/` | Run manifest files generated by the study pipeline. |
| `manuscript/` | Final manuscript files, when included. |

## Manuscript Tables and Figures

Manuscript tables were constructed directly in Microsoft Word from the released machine-readable study outputs. Separate table CSV files are not included. The repository manifest identifies the source artifacts used to support each manuscript table and figure.

The final figures used in the paper are provided in the `figures/` directory. Figure-generation and validation materials are provided in the `notebooks/` directory.

## InterLink Source Code Status

The proprietary InterLink Research Platform source code is not publicly released in this repository.

The released notebooks, generated outputs, figures, architecture documentation, and manifest files are provided to support independent inspection of the reported analyses, reproduction of manuscript figures, verification of manuscript tables, and review of the empirical outputs used in the study.
